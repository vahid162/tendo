# شبیه‌ساز دو چشم تندو — راهنمای فارسی

**[راهنمای کامل فارسی نصب و استفاده](README.md#راهنمای-کامل-فارسی) در README اصلی همین پوشه نگه‌داری می‌شود.** متن انگلیسی در ابتدای همان فایل است؛ دستور واحد Windows PowerShell نیز در بخش [نصب ویندوز](README.md#windows-one-command-setup) قرار دارد.

این شبیه‌ساز بر پایهٔ Firmware `v0.10.0-rc.8`، ESP32-S3-N8R2 و دو نمایشگر GC9A01 با رزولوشن ۲۴۰×۲۴۰ است. VS Code باید از قبل نصب باشد؛ نصب‌کننده بقیهٔ ابزارها را بررسی و آماده می‌کند.

از راهنمای کامل به‌ترتیب استفاده کن: اجرای دستور، انتخاب مسیر، ورود مخفی توکن شخصی، فعال‌سازی جداگانهٔ مجوز افزونه، شروع شبیه‌سازی در VS Code و آزمایش PET، FOOD، SLEEP و Blink. توکن را در Git یا فایل پروژه ذخیره نکن.

تأیید گرافیکی هم‌زمان دو چشم هنوز به اجرای واقعی و مشاهده نیاز دارد. کامپایل موفق، پیام `EYES READY` یا عبور تست‌های ساختگیِ اعتبارسنج تصویر، جای این مرحله را نمی‌گیرد. نتیجهٔ اجرای نصب خودت در `.tando-install.json`، لاگ `sim-smoke.log` و پوشهٔ `screenshots` ثبت می‌شود.
