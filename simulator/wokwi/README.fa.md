# شبیه‌ساز دو چشم تندو

این پروژه بر اساس Firmware نسخه 0.10.0-rc.8 شاخه develop ساخته شده است.
دو نمایشگر GC9A01 گرد 240x240 به برد ESP32-S3-N8R2 متصل شده‌اند.

## فایل‌های اصلی
- sketch.ino: کد تندو در حالت شبیه‌سازی
- diagram.json: مدار و اتصال دو چشم
- gc9a01.chip.c و gc9a01.chip.json: مدل نمایشگر
- gc9a01.chip.wasm: خروجی کامپایل‌شده مدل نمایشگر (داخل بسته ZIP)
- platformio.ini و wokwi.toml: تنظیمات ساخت و اجرا با CLI
- README.md و BUILD.md: راهنمای فنی
- COLLABORATION.md: راهنمای همکاری و Pull Request

## راه‌اندازی
1. بسته ZIP را باز کن یا شاخه feature/wokwi-dual-gc9a01 را از GitHub دریافت کن.
2. از پوشه simulator/wokwi فایل مدار و فایل کد را بررسی کن.
3. از طریق PlatformIO کد را کامپایل کن یا فایل Firmware آماده را از GitHub Actions بگیر.
4. برای شبیه‌سازی آنلاین از Wokwi CLI استفاده کن. این کار به توکن حساب خودت نیاز دارد.
5. برای آزمایش، از Serial Monitor فرمان‌های زیر را وارد کن.

## نتیجه آزمون‌ها
- تست ساختار مدار: موفق
- Wokwi CLI lint: بدون خطا
- GitHub Actions: کامپایل Firmware و WASM موفق
- اجرای تصویری هم‌زمان دو چشم در Wokwi: هنوز تأیید نشده است، چون توکن Wokwi در دسترس نبود.

کد اصلی محصول در ریشه مخزن دست‌نخورده باقی مانده است.
این بسته یک نسخه مستقل و قابل همکاری از شبیه‌ساز است.
