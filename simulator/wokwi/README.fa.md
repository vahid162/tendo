# شبیه‌ساز دو چشم تندو

[راهنمای فارسی نصب و استفاده](README.md#راهنمای-کامل-فارسی) در README همین پوشه است.
شبیه‌ساز از منبع ماژولار مشترک فریم‌ور ساخته می‌شود؛ نسخه و Commit واقعی نصب را
در `VERSION` و `.tando-install.json` ببین.

VS Code باید از قبل نصب باشد. نصب‌کننده ابزارها را آماده می‌کند، شاخه و کار محلی
را حفظ می‌کند و نتیجهٔ ساخت، اجرای ابری و بررسی تصویر را جدا گزارش می‌دهد.
توکن CLI و مجوز افزونهٔ VS Code جدا هستند. برای ارسال `p` و `v` از **Wokwi Terminal**
استفاده کن. هر دو چشم و سرعت واقعی آخرین ROI همچنان به اجرای واقعی نیاز دارند.

- [همکاری و ثبت شواهد](COLLABORATION.md)
- [نصب‌کننده](install.ps1)
